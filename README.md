- Интеграция с платежными системами

### 📈 Отчеты и аналитика
- Детальные отчеты по всем аспектам бизнеса

## 🛠 Технологии

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite (мгновенная перезагрузка)
- **UI Framework**: Material-UI (MUI) v5
- **Charts**: Recharts
- **Animations**: Framer Motion
- **Forms**: React Hook Form + Yup
- **HTTP Client**: Axios
- **State Management**: React Query
- **Routing**: React Router v6
- **Notifications**: React Hot Toast

## 🚀 Быстрый старт

### Предварительные требования
- Node.js 16+ 
- npm или yarn

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd nek-service-crm
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npm run dev
# или
npm start
```

4. Откройте [http://localhost:3000](http://localhost:3000) в браузере

### 🚀 Преимущества Vite

- **Мгновенная перезагрузка** - изменения отображаются мгновенно
- **Быстрая сборка** - в 10-100 раз быстрее Create React App
- **Оптимизированная разработка** - горячая перезагрузка модулей
- **Современный ES модули** - нативная поддержка ES модулей

### Тестовые учетные записи

Учётные записи создаются при регистрации организации на сайте. Для локальной разработки используйте `api/seed_admin.sql.example` и задайте пароль вручную.
